# Event prep: peaking and taper for a date

Status: backlog
Proposed increment: 2

Source: ruled out of the 8-week MVP in MVP scope per Pillar, including Nutrition depth (`.scratch/mvp-plan/issues/12-mvp-scope.md`).

## What

The user sets an event date (HYROX race, padel tournament, kite trip) and the Program peaks and tapers toward it.

## Why not in the MVP

The MVP plans in a steady weekly rhythm; date-driven periodization adds Block logic and testing.

Training generation model.
