# Core screens: Today, Session, Meals, Progress

Type: prototype
Status: open
Blocked by: 12, 15, 19

## Question

How should the four core screens look and behave mobile-first: Today (what to do now across Pillars, what to eat and drink, Check-in prompt, quick "I played a game" Activity log, pending Adaptation suggestions to accept or decline), Session (exercise flow, set logging with RPE/RIR, rest timer, swaps), Meals (targets and suggestions at the chosen Nutrition depth, hydration), Progress (adherence, load trends including Activities, Adaptations explained)? Rough prototype plus design-system basics (type scale, colour tokens, spacing, components) on the chosen component base.
