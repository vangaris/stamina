# Training generation model: periodization, progression, padel module

Type: grilling
Status: open
Blocked by: 01, 11, 12

## Question

Starting from Vang's seed program, what is the model that turns a user's goals, sport, equipment, schedule and level into a Program and adapts it: Block structure and periodization scheme, Session templates, exercise selection rules, progression rules (RPE/RIR targets, load/rep progression, deloads), Adaptation triggers from Logs and Check-ins (missed Sessions, high RPE, poor sleep, soreness), the exercise library schema, and the padel module (on-court load, injury-prone areas, in-season vs off-season)? Must allow more sport modules later (kite is out of scope for this map).
